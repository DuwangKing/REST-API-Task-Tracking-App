# REST API Task Tracking App

Учебный REST API для управления задачами (Todo-лист). Проект демонстрирует навыки бэкенд-разработки на .NET, включая работу с реляционными базами данных, валидацию входных данных, контейнеризацию и покрытие кода модульными тестами.

## Технологический стек

- **Язык:** C#
- **Фреймворк:** .NET 8 (Minimal API)
- **База данных:** PostgreSQL 15
- **ORM:** Entity Framework Core (Npgsql)
- **Валидация:** FluentValidation
- **Тестирование:** xUnit, EF Core In-Memory Database
- **Контейнеризация:** Docker, Docker Compose
- **Документация API:** Swagger / OpenAPI

## Основные возможности

- Полный цикл CRUD-операций для управления задачами
- Автоматическое применение миграций базы данных при запуске
- Валидация входящих данных с помощью FluentValidation
- Взаимодействие с БД через EF Core с использованием миграций
- Покрытие бизнес-логики модульными тестами
- Запуск всего стека (API + PostgreSQL) одной командой через Docker
- Автоматически генерируемая документация API (Swagger UI)


## Инструкция по запуску

Через Docker

Самый простой способ — запустить всё одной командой. Требует установленного Docker и Docker Compose.

# Клонируйте репозиторий
git clone https://github.com/DuwangKing/REST-API-Task-Tracking-App.git
cd REST-API-Task-Tracking-App

# Запустите приложение и базу данных
docker compose up --build

## Архитектурные решения
-Dependency Injection: все сервисы регистрируются в DI-контейнере и внедряются через конструктор или параметры эндпоинтов
-Scoped lifetime: AppDbContext и ITodoService живут в рамках одного HTTP-запроса
-Автоматические миграции: при запуске приложения EF Core автоматически применяет недостающие миграции (Database.Migrate())
-FluentValidation: валидация входных данных вынесена в отдельные классы-валидаторы и подключается через middleware
