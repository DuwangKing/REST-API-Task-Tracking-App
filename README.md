# REST API Task Tracking App

Учебный **REST API для управления задачами (Todo-лист)**. Проект демонстрирует навыки бэкенд-разработки на .NET, включая работу с реляционными базами данных, валидацию входных данных, контейнеризацию и покрытие кода модульными тестами.

---

##  Технологический стек

* **Язык:** C#
* **Фреймворк:** .NET 8 (Minimal API)
* **База данных:** PostgreSQL 15
* **ORM:** Entity Framework Core (Npgsql)
* **Валидация:** FluentValidation
* **Тестирование:** xUnit, EF Core In-Memory Database
* **Контейнеризация:** Docker, Docker Compose
* **Документация API:** Swagger / OpenAPI

---

##  Основные возможности

* **CRUD-операции:** Полный цикл создания, чтения, обновления и удаления задач.
* **Автомиграции:** Автоматическое применение миграций базы данных при запуске приложения.
* **Валидация:** Строгая проверка входящих данных с помощью FluentValidation.
* **Тестирование:** Покрытие ключевой бизнес-логики модульными тестами.
* **Быстрый старт:** Запуск всего стека (API + PostgreSQL) одной командой через Docker.
* **Документация:** Автоматически генерируемая интерактивная документация API (Swagger UI).

---

##  Инструкция по запуску

Самый простой способ развернуть проект — использовать Docker. Для этого на вашем компьютере должны быть установлены **Docker** и **Docker Compose**.

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/DuwangKing/REST-API-Task-Tracking-App.git
cd REST-API-Task-Tracking-App
```

### 2. Запустите приложение и базу данных
```bash
docker compose up --build
```

##  Архитектурные решения

* **Dependency Injection:** Все сервисы регистрируются в DI-контейнере и внедряются через конструктор или параметры эндпоинтов.
* **Scoped Lifetime:** Контекст базы данных `AppDbContext` и сервис `ITodoService` живут в рамках одного HTTP-запроса.
* **Database Migration:** При старте приложения EF Core автоматически проверяет и применяет недостающие миграции с помощью метода `Database.Migrate()`.
* **FluentValidation:** Логика валидации входных данных полностью вынесена в отдельные классы-валидаторы и прозрачно подключается через middleware.
